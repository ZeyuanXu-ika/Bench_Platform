QUICK GUIDE

从本地开始，在本地保存。

  1. 先从飞书下载分配的素材包，解压后导入其中的任务 JSON。
  2. 点击“选择素材文件夹”，授权浏览器读取这批文件。网页无法直接使用输入的磁盘路径。
  3. 选择证据标签，在播放器暂停位置按 [ 和 ]，再按 Enter 创建片段。
  4. 填写片段详情，标记任务完成。空格 控制播放，, / . 步进；填写文本时快捷键暂停。
  5. 点击“导出本地结果”。在支持的浏览器中可以选择保存路径；其他浏览器使用下载文件。
  6. 把导出的 JSON 上传到飞书任务表单。复标时使用各自任务 ID，不要互相覆盖结果。

重新打开网页时可以恢复浏览器草稿，但素材需要重新选择。浏览器缓存可能被清理，导出的 JSON 才是独立文件备份；也可以导入结果继续标注。

步进在清单有参考帧率时使用该帧率，否则按 0.1 秒移动。可变帧率素材的关键证据请以时间戳为准。
